## 图书管理系统（前后端分离）项目说明

本项目为**图书管理系统（前后端分离）**，包含两套端：

- **管理端（后台）**：管理员/馆员登录，用于图书、分类、读者信息、借阅记录查询、统计、账号权限等管理
- **读者端（前台）**：读者登录/注册，用于图书查询、借阅/归还、查看个人借阅记录、修改读者密码

---

## 技术栈与选型

### 前端

- **Vue 3** + **Vite**：构建与开发服务器
- **TypeScript**：类型约束，降低前端运行时错误
- **Element Plus**：后台管理 UI 组件库
- **Vue Router**：路由与页面切换
- **Pinia**：状态管理（保存登录态、用户信息）
- **Axios**：HTTP 请求（统一拦截器、错误提示）

### 后端

- **Java 17**
- **Spring Boot 3**：Web + Security + Validation
- **MyBatis**：SQL 映射（Mapper 接口 + XML）
- **MySQL**：业务数据存储
- **JWT**：无状态登录认证
- **Springdoc OpenAPI**：接口文档（Swagger UI）

## 权限与账号模型

### 角色

- **ADMIN**：管理员（拥有所有权限，包含账号管理、删除类操作）
- **LIBRARIAN**：馆员（可进行日常录入、修改、借还等；不包含管理员专属能力）
- **READER**：读者（读者端登录/注册，借阅/归还、查看个人借阅记录、修改密码）

### 登录方式

- 管理端登录：`sys_user`（ADMIN / LIBRARIAN）
- 读者端登录/注册：`reader`（READER）

### 默认管理员

- 后端首次启动时若 `sys_user` 为空，会自动创建：
  - 用户名：`admin`
  - 密码：`Admin@123456`
  - 角色：`ADMIN`

## 数据库设计（核心表）

脚本位置：`sql/schema.sql`

- `sys_user`：后台账号（管理员/馆员）
- `reader`：读者信息与读者账号（证号、密码哈希、姓名、联系方式、状态）
- `book_category`：图书分类（学科/类别等维度）
- `book`：图书信息（ISBN、书名、作者、出版社、分类、书架位置、库存等）
- `borrow_record`：借阅记录（借出/归还时间、状态、操作员等）

### 图书状态与库存

- `book.status`：`ENABLED` / `DISABLED`
- `total_qty`：馆藏总数
- `available_qty`：可借库存
- 借出：原子扣减 `available_qty`（库存不足会失败）
- 归还：增加 `available_qty`（不超过 `total_qty`）

## 已实现功能清单（对应需求）

### 1) 图书信息管理

- **图书录入**：新增图书，设置 ISBN/书名/作者/出版社/分类/书架位置/馆藏数量等
- **图书修改**：编辑图书基础信息、状态、馆藏数量（校验不能小于已借出数量）
- **图书删除**：仅管理员可删除（校验存在未归还借阅则禁止删除）
- **图书查询**：按关键字（书名/作者/ISBN/出版社/书架位置）、分类等筛选
- **分类管理**：新增/编辑/删除/分页查询/全部分类列表
- **状态管理**：通过 `ENABLED/DISABLED` 控制是否可借

### 2) 读者信息管理

- **读者登记**：新增读者（证号唯一）
- **读者修改**：编辑读者信息与状态
- **读者查询**：按证号/姓名/手机等查询
- **读者注销**：将读者状态置为 `CANCELLED`
- **借阅历史**：按读者查询借阅历史记录

### 2.1) 读者端（前台）功能

- **读者注册**：读者自助注册并设置密码（注册成功后自动登录）
- **读者登录**：读者证号 + 密码登录获取 JWT
- **图书查询**：读者端分页查询图书
- **借阅图书**：读者端借阅（服务端强制使用 token 内读者ID）
- **归还图书**：读者端归还（只能归还自己的借阅记录）
- **我的借阅记录**：查询个人借阅记录（可筛选状态）
- **账户管理**：读者修改密码

### 3) 借阅与归还管理

- **借书**：校验读者存在且未注销、图书存在且可借且库存充足、同读者同书无未归还记录
- **还书**：按借阅记录归还（状态从 `BORROWED` -> `RETURNED`，并回补库存）
- **应还时间默认**：若未指定应还时间，默认设置为借出后 30 天

### 4) 查询与统计

- **借阅记录查询**：按读者ID、图书ID、状态筛选分页查询
- **统计概览**：图书总数、可借库存、活跃读者、借出中数量、借阅记录总数等

### 5) 系统管理

- **用户权限管理（角色）**：`ADMIN/LIBRARIAN` 角色控制接口访问
- **密码修改**：登录后可修改自己的密码
- **账号管理**：管理员可新增/编辑/禁用/删除账号、重置密码

## 后端主要接口概览（REST）

统一返回：`{ code, message, data }`，`code == 0` 表示成功。

### 认证与个人设置

- `POST /api/auth/login`：登录（返回 JWT）
- `GET /api/auth/me`：获取当前登录用户信息
- `POST /api/auth/change-password`：修改当前账号密码

### 读者端认证

- `POST /api/reader-auth/register`：读者注册（注册成功后返回 JWT）
- `POST /api/reader-auth/login`：读者登录（返回 JWT）
- `GET /api/reader-auth/me`：读者获取当前登录信息
- `POST /api/reader-auth/change-password`：读者修改密码

### 读者端业务

- `GET /api/reader/borrows`：我的借阅记录（可按状态筛选）
- `POST /api/reader/borrow`：读者借书
- `POST /api/reader/return`：读者还书（仅能归还自己的记录）

### 图书与分类

- `GET /api/books`：图书分页查询
- `POST /api/books`：新增图书（馆员/管理员）
- `PUT /api/books/{id}`：编辑图书（馆员/管理员）
- `DELETE /api/books/{id}`：删除图书（仅管理员）
- `GET /api/categories`：分类分页查询
- `GET /api/categories/all`：分类列表（下拉用）
- `POST /api/categories`：新增分类（馆员/管理员）
- `PUT /api/categories/{id}`：编辑分类（馆员/管理员）
- `DELETE /api/categories/{id}`：删除分类（仅管理员）

### 读者

- `GET /api/readers`：读者分页查询
- `POST /api/readers`：新增读者（馆员/管理员）
- `PUT /api/readers/{id}`：编辑读者（馆员/管理员）
- `POST /api/readers/{id}/cancel`：注销读者（馆员/管理员）

### 借阅归还与记录

- `GET /api/borrows`：借阅记录分页查询
- `GET /api/borrows/reader/{readerId}`：读者借阅历史
- `POST /api/borrows/borrow`：借书（馆员/管理员）
- `POST /api/borrows/return`：还书（馆员/管理员）

### 统计

- `GET /api/stats/overview`：概览统计

### 账号管理（仅 ADMIN）

- `GET /api/users`：账号分页查询
- `POST /api/users`：新增账号
- `PUT /api/users/{id}`：编辑账号
- `POST /api/users/{id}/reset-password`：重置密码
- `DELETE /api/users/{id}`：删除账号

## 数据库初始化与启动要点

### 1) 创建数据库与建表

- 你可以直接在 MySQL 客户端里创建数据库（推荐名：`library_ms`），然后执行 `sql/schema.sql`。
- `schema.sql` 兼容 MySQL 5.7+/8.0+（避免了 MySQL 8 专属排序规则）。

### 2) 后端配置

- 修改 `backend/src/main/resources/application-dev.yml` 中：
  - `spring.datasource.url`
  - `spring.datasource.username`
  - `spring.datasource.password`
- 建议将 `application.yml` 中 JWT 的 `secret` 改成你自己的随机长串（32+ 字符）。

### 3) 前端配置

- 开发时前端会通过 Vite 代理转发 `/api` 到 `http://localhost:8080`
- `vite.config.ts` 已配置 `@` 别名为 `src`
